# 蛋岛桌面宠物

从 [eggislandgame.xyz](https://eggislandgame.xyz) 扒下来的 3D 角色，做成桌面挂件。

Electron + Three.js，透明置顶窗口，悬浮在屏幕角落。

## 角色

| 名字 | 模型 |
|---|---|
| 蛋糕纯 | `character-cake.glb` |
| 珠玉纯 | `character-jade.glb` |
| 小蛋（跟宠） | `pet-egg.glb` |

三个模型都**没有动画 clip**，只有骨骼。动画是用站点自己的 `renderer/animation.js`
（`setupCharacterRig` / `setupPetRig` + `updateRig`）程序化驱动骨骼实现的——
呼吸、悬浮、坐姿、转头全靠每帧算。小蛋是蛋岛原版跟宠模型，82 根骨骼，会自己飘、摇、眨眼。

## 召唤

启动后她只露 3 秒，然后自动躲起来——不常驻屏幕。

- **Ctrl + Alt + E**：召唤 / 收起
- 点右下角托盘图标也行

被召唤出来时会蹦一下、转半圈。

## 操作

| 操作 | 效果 |
|---|---|
| 左键拖动 | 360° 旋转角色（带惯性） |
| 右键拖动 | 移动窗口 |
| 右键单击 | 菜单：小蛋助手 / 待机节目 / 放首歌 / 换角色 / 退出 |
| 左键单击角色 | 播放 / 暂停音乐（顺带跳一下） |
| 左键单击小蛋 | 它会跟你说句话、撒一把爱心 |
| 双击 | 打开聊天窗口 |

透明区域不挡桌面点击，只有角色和小蛋本体拦截鼠标。窗口固定 200×200，拖动时也会锁死尺寸。

## 放音乐

点她就会播放。歌放在：

```
%APPDATA%\EggIslandPet\music
```

右键菜单里有 **「打开音乐文件夹」**，点一下直接打开，把 mp3 / m4a / wav / flac 拖进去就行。
支持多首，按文件名顺序循环，一首放完自动下一首。

**歌要你自己准备**——版权在平台和歌手手里，程序只负责播本地文件。

## 待机节目（11 套，自动轮换不重样）

灵感取自 GitHub 上的桌面宠物项目：**Bongo Cat**（呼吸待机、点击连击、漂浮数字反馈）和
**Shimeji**（一堆互不重复的小动作、满屏乱走）。照着「把好玩的都留下」的思路做了一整张节目单，
每隔几秒随机换一套，不会连着重复：

| 节目 | 样子 |
|---|---|
| 站着发呆 | 呼吸起伏、缓慢东张西望 |
| 坐一会儿 | 坐下，腿前伸垂着 |
| 荡秋千 | 横杆水平、绳子座板齐全，**人是坐着的**，轻轻左右荡 |
| 转个圈 | 真转满 360°，转完自动回正面 |
| 蹦蹦跳 | 连续起跳 + 落地压扁回弹 |
| 散步开花 | 在窗口里左右走，**每落一步脚下开一朵花** |
| 满地开花 | 四周依次绽开六瓣花，偶尔飘落花瓣 |
| 挥手打招呼 | 抬手来回摆 + 撒爱心 |
| 飘起来 | 整个人浮起来，星星一粒粒往上冒 |
| 追小蛋 | 跟着小蛋左右转头 |
| 打瞌睡 | 坐下，Zzz 慢慢飘 |

### 小蛋跟宠

蛋岛原版 `pet-egg.glb`，不是额外画的光球：圆滚滚的 Q 版小蛋，有脸、有小手小脚，
带一圈柔光和拖尾光点，绕着角色飞、轻轻上下摇。按 **F** 或右键菜单可以关掉 / 打开。
它不只是摆设，具体能干什么见下一节。

### 点击反馈

- 单击：飘爱心 / 星星、蹦一下、转个身、冒一句小台词，顺便放歌
- **连击**：越点越夸张，第 3 下起满地开花，第 6 下起换成星星雨 + 「×N 连击」气泡
- 手动转过之后约 1.8 秒会**自动转回正面**

### 怎么自己翻

| 方式 | 效果 |
|---|---|
| 右键 →「换个节目」/「待机节目」 | 随机换一套，或直接点名某一套 |
| 按 `A` | 立刻换一套 |
| 按 `F` | 小蛋开关 |
| 按 `1` / `2` | 切蛋糕纯 / 珠玉纯 |

## 小蛋助手（不是摆设）

照着 GitHub 上几个成熟桌宠项目，把「真能用」的部分挑出来做了：

| 参考 | 借来的能力 |
|---|---|
| [DeskPet Live2D](https://github.com/tcmiku/tools_live2D) | 健康提醒、番茄钟、专注追踪 |
| [Toty](https://toty.fun/) | 20-20-20 护眼、喝水 / 拉伸提醒、日常陪伴 |
| [SUDARI](https://github.com/seojaeohcode/SUDARI) | 番茄钟；**提醒做成角色的一句话，而不是系统弹窗** |
| [Desktop-pet](https://github.com/gcloudream/Desktop-pet) | 按时段切换问候、疲劳感 |
| [Mintu](https://github.com/HuseynDeveloper/Mintu) | 屏幕感知、智能剪贴板 |

### 它主动做的

- **护眼**：默认每 30 分钟一句「看看远处 20 秒～」，菜单可改 20 / 30 / 45 / 60 分钟或关掉
- **喝水**（60 分钟）、**起身**（90 分钟）、**深夜别熬**（23:00–03:00）
- **情绪陪伴**：每 28 分钟随机一句关心 / 夸夸，可关
- 提醒**不弹系统通知**：小蛋短暂露脸，从角色身上冒出半透明玻璃气泡说一句话，说完自己缩回去，
  依旧不常驻。菜单里关掉「提醒时露个脸说」后，话会攒着，等你召唤时一起说。

### 你叫它做的

| 右键菜单 | 做什么 |
|---|---|
| 看看我在干嘛 | 截一次屏 → 发给配好的视觉模型 → 小蛋说一句贴心话。**只在你点的时候截**，不偷偷上传 |
| 复制的内容帮我看看 | 读剪贴板 → 一句话概括 + 一个实在建议，看代码 / 报错 / 英文时顺手 |
| 开始 / 停止专注 25 分钟 | 番茄钟，结束撒花庆祝，5 分钟后喊你回来 |
| 点一下小蛋 | 冒一句随机台词 + 爱心 |

两个「帮我看看」要模型 API，聊天窗 ⚙ 里配好 DeepSeek / Ollama 就能用。

## AI 对话

双击角色打开聊天窗（半透明玻璃质感），点右上角 ⚙ 填接口（OpenAI 兼容格式）：

- 本地 Ollama：`http://localhost:11434/v1`，模型填 `ollama list` 里的名字，Key 随便写
- 云端：`https://api.deepseek.com/v1` + 你的 Key + `deepseek-chat`

请求走主进程转发，绕开渲染层 CORS。

### 三种输入方式

| 方式 | 说明 |
|---|---|
| 打字 | Enter 发送，Shift+Enter 换行 |
| 🎤 按住说话 | 用 Web Speech API。**Electron 内置识别要连 Google，国内基本不可用**，失败会提示，别指望它 |
| 👁 看屏幕 | 截当前屏幕发给视觉模型 |
| ⬚ 圈一块 | **自由套索**，可以画任意形状。圈完不自动提问——先出现缩略图和「这是什么」按钮，你想问什么就打字或说话 |

### 语音朗读

右上 🔊 开关。用**微软 Edge 神经语音**（`msedge-tts`），比 Windows 自带的 SAPI 自然得多。
默认晓晓，设置里可以换成晓伊 / 晓辰 / 晓涵 / 云希（男）/ 小北（东北话）。

需要联网合成，句子短的话几十毫秒就好。合成失败会自动回退到系统 TTS。

**不做名人声音克隆**——声音权参照肖像权受《民法典》1023 条保护，未经本人授权克隆他人声音属于侵权。

### 做不到的

**接不进 WorkBuddy**——它没有对外接口。她只能跟你配的模型 API 或本地 Ollama 说话。

## 实现要点（踩过的坑）

1. `three.module.js` 只是个入口，真正实现在同目录 `three.core.js`，两个都得有。
2. `file://` 下加载 ES module 会失败，报错信息会误导成 CORS——实际是依赖文件没下全。
3. 相机按模型高度自适应，人物和宠物才能都占满画面约 3/4。
4. 窗口用 `setIgnoreMouseEvents(true, { forward: true })` 实现透明区穿透，
   渲染层用 raycast 判定是否悬停在模型上再切回可点击。
5. 透明窗口里 WebGL Sprite 粒子几乎看不见（加色混合 + 窗口 alpha 合成会糊成灰团），
   换成 DOM 覆盖层 + CSS 动画后颜色立刻鲜亮。`capturePage()` 抓不到 CSS 动画层，
   验证特效要用桌面截图。
6. `lastRotateAt` 必须和 `tick()` 一样用 `performance.now()`；之前点击里写了 `Date.now()`，
   两者差 1.7e12 毫秒，自动回正永远不触发。
7. 长按右键拖动时系统偶尔把透明窗口撑大：主进程 `setBounds` 带固定宽高、`resize` 时锁回，
   渲染层再把 `camera.aspect` 钉死为 1，双保险。
